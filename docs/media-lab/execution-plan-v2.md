## 1. 这次重排解决什么

目标是交付一个供单人使用的 Windows 本地内容生产助手：从自有/授权素材中找到合适镜头，分析仅供参考的内容模式，生成原创脚本与分镜，并生成剪映可执行的交接包；每次项目都以新手可确认、可恢复的步骤清单推进。

不做完整非线性剪辑器、剪映自动化、社媒自动发布、爬取、云端渲染或本地模型。参考素材绝不进入最终可用候选或导出。

本计划也修正执行方式：禁止以“继续开发中”作为没有实质进展的回复。每个循环只能是：完成一个可验证切片、报告一个真实阻塞，或等待必须由操作者决定的事项。

## 3. 当前切片：可靠本地任务底座

**范围**：完成可取消、可重试、可观测的 main-process 任务服务，先服务于素材索引和 FFmpeg 工作；不接入 AI 生成或渲染。

**已修正的语义**：进程中断时，`running` 任务恢复为 `queued`；`cancel_requested` 任务恢复为 `canceled`，不能留在不可领取的伪排队状态。

**验收**：

1. 任务只能由单个领取者从 `queued` 原子转为 `running`。
2. 取消请求可被执行器观察；重启后不会重新执行被取消的工作。
3. 每次失败有错误码、尝试次数和上限；达到上限时结束为 `failed`。
4. 任务重启恢复、取消、重试均有 SQLite 集成测试；不触碰原始媒体。
5. 通过聚焦测试、全量测试、类型检查、lint、构建和一次 Electron 冒烟。

**回滚**：应用代码回退；`011_local_jobs_v2` 数据列保留，不自动删除用户数据。

## 4. 后续阶段与硬性退出门槛

### P1 素材库与媒体索引

完成文件夹授权、哈希去重、移动/丢失检测、重新关联、缩略图/关键帧/代理文件、缓存清理和素材版权信息。退出门槛：使用临时自有媒体的集成测试证明原文件哈希未变，缓存可删、索引可恢复。

### P2 参考分析与模式卡

严格隔离参考与自有资产，离线提取必要关键帧/音频后调用可 mock 的 AI provider，输出版本化 Pattern Card。退出门槛：契约测试证明参考资产不能成为镜头候选或导出输入；成本、缓存和失败状态可查询。

### P3 创意规划与跨格式内容

基于 Pattern Card、事实证据和自有素材生成视频、图片/轮播、平台文案的原创方案；所有 AI 输出经 Zod 验证，用户确认后才写入项目。退出门槛：同一项目能生成可审阅的 Storyboard、静态图说明和文案包，且未确认提案不会改写版本。

### P4 剪映交接与完整新手教程

输出编号素材、剪辑表、SRT、封面、平台文案、版权/证据清单和核验哈希；为 Media Lab、剪映和手动发布提供逐步确认与恢复。退出门槛：从一个最小自有素材项目生成原子交接目录；新手清单重启后仍回到准确步骤。

### P5 端到端验收与 Windows 交付

完成中文 UI 的错误/空状态、Electron E2E、安装包、无密钥扫描和人工剪映观察记录。退出门槛：干净 Windows 配置可安装启动；mock AI 走完“导入→分析→交接→清单确认”；任何外部发布保持人工操作。

## 5. 每阶段固定质量流程

在改动前写最小失败测试；只做使它变绿的改动；随后执行相应的集成测试、类型检查、lint、构建和 UI/Electron 验证。每阶段单独提交并更新 handoff。网络、GitHub 或第三方 API 不可达时，记录为阻塞，绝不伪称已同步或已验证。
